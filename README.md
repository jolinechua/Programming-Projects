# **Data Analysis with Python**

This repository contains two projects showcasing data analysis, algorithm implementation and statistical modeling using Python. These projects demonstrate technical proficiency in data visualization, statistical analysis and machine learning.

---

## **Project 1: Metropolis-Hastings Algorithm**

### Overview
- **Objective:** Implement the Metropolis-Hastings Algorithm to generate random samples from a custom probability density function.
- **Main Points:**
  - Visualize data using histograms, kernel density estimates (KDE), and the defined probability density function.
  - Compute the R-hat statistic to assess convergence in Markov Chain Monte Carlo (MCMC) sampling.
- **Tools Used:**
  - Python (NumPy, Matplotlib, Seaborn)

### Outputs
- Plots showing sample distributions and R-hat convergence diagnostics.

## **Project 2: Flight Delay Analysis and Logistic Regression**

### Overview
- **Objective:** Analyze commercial flight data from the US (1994–2003) to determine:
  - Optimal times and days to minimize delays.
  - Whether older planes experience more delays.
  - Predict flight diversions using logistic regression.
- **Main Points:**
  - Database creation using SQLite.
  - SQL integration with Python for querying and analysis.
  - Visualizations and modeling with Matplotlib, Seaborn, and Scikit-learn.
- **Tools Used:**
  - Python (pandas, Matplotlib, Seaborn, Scikit-learn)

### Outputs
- Bar charts, scatterplots, and logistic regression visualizations.
- High-accuracy predictions of flight diversions.
